SOLAB - Soporte del Sistema Operativo (Grupo 5)
1) Descomprime el .zip y abre la carpeta en Visual Studio Code (Archivo > Abrir carpeta).
2) Pulsa F5 (Ejecutar > Iniciar depuración) y elige Chrome/Edge: se abre la web.
   Alternativa: extensión "Live Server" > clic derecho en index.html > Open with Live Server.
   Tambien funciona con doble clic en index.html. No requiere internet ni instalar nada.
